# Changelog

All notable changes to the Tellscript format and this repository. Entries are written by
[release-please](https://github.com/googleapis/release-please) from the pull request titles.

## 0.1.0 (2026-09-27)

### Features

* First public draft of the Tellscript format: files, front matter, layers, rings, statements, proof levels and
  editions ([spec/draft.md](spec/draft.md)).
* JSON Schema for the front matter and a checker for `.tell.md` files.
* The `tellscript` agent skill, installable with `npx skills add tellscript-dev/tellscript` and as a Claude Code plugin.
* Documentation and the Castwell example.
